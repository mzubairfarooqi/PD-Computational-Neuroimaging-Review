# Contributing

Contributions that improve the usefulness of this companion repository are welcome.

## Good contributions

- New PD neuroimaging datasets with a stable official access page.
- Public code repositories associated with peer-reviewed PD neuroimaging studies.
- Reproducible preprocessing, validation or harmonization resources.
- Corrections to dataset metadata or links.
- Newly published work directly relevant to the review scope.

## Please include

For a dataset:
- name;
- modality;
- cohort/task;
- access type;
- official URL;
- citation or DOI where available.

For a study/code resource:
- full paper title;
- year;
- modality;
- computational method;
- clinical task;
- DOI/publisher link;
- code link if public.

## Do not submit

- Patient-level clinical data.
- Controlled-access imaging files.
- Credentials, tokens or API keys.
- Copyrighted figures from third-party papers without permission.

Please keep descriptions factual and avoid ranking studies solely by reported accuracy because target tasks and validation designs differ substantially.
